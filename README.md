# Planificateur d'études & Récompenses (add-on Anki)

Add-on Anki (2.1.55+) qui transforme les révisions en jeu : planning d'examens, XP et niveaux, pièces à dépenser, boutique de cosmétiques, boss à combattre pendant les révisions, université à construire, collection de spécimens et un casino.

## Fonctionnalités

- **Planning** : objectifs quotidiens calculés à partir des dates d'examen.
- **XP, niveaux et mascotte** qui évolue, avec une barre d'infos discrète pendant les révisions.
- **Pièces** gagnées à chaque carte, dépensables en boutique, en temps de vidéo ou en récompenses personnelles.
- **Boss** : attaques, quiz et chrono-défis intégrés au panneau du boss.
- **Université**, **collection**, **badges**, **coffres de série**.
- **Casino** (ouvert après avoir terminé un paquet) : machine à sous à levier, roulette, mines, plinko, fusée. Tous les jeux sont équitables : aucun avantage pour la maison.
- **Météo** : bonus de pièces quand il pleut dans ta ville.

## Installation

1. Ouvre le dossier des add-ons : Anki → Outils → Modules complémentaires → Afficher les fichiers.
2. Copie ce dépôt dans un dossier `planificateur_etudes`.
3. Redémarre Anki.

Les réglages sont dans Outils → Modules complémentaires → Configurer (voir `config.md`). Ta progression est enregistrée dans `user_files/`.
