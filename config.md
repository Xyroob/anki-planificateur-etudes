**marge_jours_defaut** : nombre de jours avant l'examen où toutes les nouvelles cartes doivent être vues (valeur proposée quand tu ajoutes un examen).

**objectif_revisions_sans_examen** : objectif quotidien (nombre de révisions) quand aucun examen n'est prévu.

**xp_par_revision** : XP gagnée pour chaque carte révisée, quelle que soit ta réponse.

**xp_bonus_nouvelle_carte** : bonus pour chaque nouvelle carte vue pour la première fois.

**bonus_objectif_atteint** : bonus quand l'objectif du jour est atteint (+10 par jour de série, max +100).

**notification_toutes_les_n_cartes** : petit message d'encouragement toutes les N cartes (0 = désactivé).

**prix_10_minutes_video** : prix en pièces de 10 minutes de vidéo (20 et 45 minutes sont un peu moins chères à la minute).

**site_video** : le site ouvert comme récompense (YouTube par défaut).

**pieces_a_revoir / pieces_difficile / pieces_correct / pieces_facile** : pièces gagnées selon ta réponse. Correct et Facile rapportent pareil pour ne jamais te pousser à surévaluer une carte.

**pieces_bonus_nouvelle_carte** : pièces en plus pour chaque nouvelle carte vue.

**pieces_bonus_objectif** : pièces quand l'objectif du jour est atteint (+20 par jour de série, max +200).

**casino_mises_par_billet / casino_mise_max** : nombre de mises gagnées pour chaque paquet terminé dans la journée, et mise maximum par partie. Les jeux du casino sont équitables : aucun avantage pour la maison.

**ville_meteo** : ville utilisée pour la météo (fond « Météo en direct », bonus de pluie, campus). Modifiable aussi dans la Boutique.

**bonus_pluie_pourcent** : pièces en plus pendant qu'il pleut.
